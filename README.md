# Portfolio

Personal portfolio of **Kabhilan V. S**, full-stack and AI developer.

Live site: https://kabhilan-vs-05.github.io/Portfolio/

## Features
- Responsive single page with dark and light themes (remembers your choice)
- Project filters (AI, full-stack, mobile, award winning) and live search
- Scroll progress bar, active section highlight, count-up stats, typing role line
- Live public repository count from the GitHub API
- Contact form that opens your email app
- Accessible: keyboard navigation, skip link, reduced-motion support

Built with plain HTML, CSS and JavaScript. No build step, no frameworks, hosted on GitHub Pages.
